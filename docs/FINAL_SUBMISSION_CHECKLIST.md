- [ ] `git status` clean; commit history shows each person's contributions.

- [ ] Next.js interface and database/API integration demonstrated end-to-end.
- [ ] Admin and technician roles, authentication, authorization and database validation tested.

- [ ] Screenshots include actual UI, SQL, MongoDB, and security tests.
- [ ] Documentation includes objectives, functional requirements, schema/data dictionary, justification, architecture, queries, testing and conclusion.
